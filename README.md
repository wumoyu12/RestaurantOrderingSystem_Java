## Overview

This project is a simple restaurant ordering system built using Java.

It allows users to select meals from different categories (breakfast, lunch, and dinner), place orders, and view a final receipt.

The purpose of this project is to practice basic programming logic, user input handling, and simple system design.

**Built with:** Java

---

## Features

* Menu selection (Breakfast, Lunch, Dinner)
* Input validation (handles invalid numbers and text input)
* Order tracking
* Receipt generation (without tax calculation)

---

## Project Structure

* **code** – Java source code for the system
* **archive** – downloadable ZIP version of the project

This is a console-based project focused on fundamental programming concepts and structure rather than advanced features or UI.
